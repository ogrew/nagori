# Nagori

https://ogrew.github.io/nagori/

辞書の項目を一つずつ縦書きで並べ、項目の字数だけで波を描く Web 作品。

- 1列＝辞書の1項目「【見出し（よみ）】語釈。」。項目はどこも切らず、字数がそのまま列の長さになる
- 上の波と下の波が向かい合う。下の列の字数は上の列と足して一定になるので、2つの波のあいだの隙間が同じ幅のまま揺れる
- 見出しはよみのしりとりでつながる。つながるかなは一瞬だけ白黒反転する
- 波形（sin 波・三角波・のこぎり波・|sin| 波・矩形波）と始まりの位相は、開くたびにランダム

### Uzu（渦）

https://ogrew.github.io/nagori/uzu.html （設定の MODE で切り替え）

- 同じ辞書の項目を渦巻きに沿って並べ、見出しをしりとりでつなぐ
- 半周ごとに語がちょうど終わるよう字数を合わせて語を選ぶので、中心を横切る区切りの線が見える
- 中心から外周へ、外周まで来たら同じ道を逆にたどって中心へ、と往復する。前の周回の字は消さずに、半周ずつ上書きする（前の周回は薄く残る）
- 字は進む方向に1字ずつ回す

### Kuruwa（郭）

https://ogrew.github.io/nagori/kuruwa.html （設定の MODE で切り替え）

- 同じ辞書の項目を、外周から内へ巻き込む四角の渦（右・下・左・上の棒）に並べ、見出しをしりとりでつなぐ
- 1本の棒に語がちょうど収まるよう字数を合わせて語を選ぶ
- いちばん内側まで来たら、同じ棒を逆にたどって外周へ戻り、往復する。前の周回の字は消さずに、棒ごとに上書きする

## 操作

| キー | 動作 |
|---|---|
| Space | 開始・停止 |
| H | 設定の表示・非表示 |
| S | 画像（PNG）を保存（フェードを外した状態） |

## 辞書データ

`dict.json` は [Wiktionary 日本語版](https://ja.wiktionary.org/) の項目を、[kaikki.org](https://kaikki.org/) / [wiktextract](https://github.com/tatuylonen/wiktextract) による抽出データ（2026-11-02 版）から加工したものです。
ライセンスは [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja) です。

加工の内容：日本語の項目から、見出し・読み・最初に使える語釈を取り出し、記号を含むもの・他の項目を参照するだけのもの・JIS 第1水準外の漢字を含むものなどを除き、読みのない項目には形態素解析（UniDic）で読みを補っています。
